Database security & RDS Proxy migration

2026 · MapMyCrop

A production database suffered recurring connection pressure while its network exposure was wider than it should be. I traced the cause, closed the gaps, and planned the fix for zero downtime to the application.

Close public DB ports→ Least-privilege SGs→ Secrets Manager→ Fix idle-connection leaks→ RDS Proxy cutover
PROBLEMRecurring connection pressure on production, and database ports reachable from the public internet.
ROOT CAUSEIdle connections leaking from scheduled pipelines, plus overly broad network access.
PREVENTIONConnection pooling via RDS Proxy, dedicated least-privilege Security Groups, and secrets only from Secrets Manager.
